# Project instructions

- For Watchbox architecture design, review, refactoring, or browser portability work, use the [Watchbox architecture skill](.agent/skills/watchbox-architecture/SKILL.md).
- Use `.github/PULL_REQUEST_TEMPLATE.md` when creating pull requests.
- Always use the [test-driven-development skill](.agent/skills/test-driven-development/SKILL.md) for development work, including new features, bug fixes, refactoring, and behavior changes. Follow RED → GREEN → REFACTOR: write a failing test first, verify the expected failure, implement the smallest change that passes, and run the full test suite. Obtain explicit user permission before making any exception.
